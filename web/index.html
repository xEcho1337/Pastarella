Pastarella

A forensic analysis tool written in C#.

Pastarella is an under development tool designed to collect data on your computer by using many different forensic analysis algorithms, providing a clear view of user activity and system state to investigators.

For doing all of its operations, Pastarella under the hood uses Scanners, classes specialized on retrieving one kind of data. The implemented scanners are:
Name Returns
Service Enabled services
Driver Drivers/LKM present on the system
Persistence Persistance points enabled or not
Network What ports are opened and by who
Command History Saved command histories
Forensic Active processes, users, drives/storage informations
Hosts Hosts file content
Environment variables The process environ
Pastarella currently supports the following operating systems:
  • Windows 10/11
  • macOS
  • Linux (WIP)
  • FreeBSD (very WIP)

The Name

Pastarella can mean different things depending on what you like the most:
  • an Italian way to say "pastry": if you are feeling hungry
  • Postmortem Analysis of System Telemetry, Artifacts, Registry, Events, Logs, Links and Activity: if you feel creative
  • a delicious forensic framework: if you ask the marketing team
  • just a pastry: if you ask my grandmother
