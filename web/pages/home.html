What is Pastarella
Under development forensic collector.

Pastarella collects data on your computer using many different forensic analysis algorithms, providing a clear view of user activity and system state to investigators.

Under the hood it uses Scanners, classes specialized on retrieving one kind of data. The implemented scanners are:

Name Returns
ServiceEnabled services
DriverDrivers and kernel modules present on the system
PersistencePersistence points enabled or not
NetworkWhat ports are opened and by who
Command HistorySaved command histories
ForensicActive processes, users, drives and storage information
HostsHosts file content
Environment variablesThe process environ

* Persistance report has a "risk score", which will be always zero apart from some Windows registry keys.

Environment variables and recent files are always collected.
